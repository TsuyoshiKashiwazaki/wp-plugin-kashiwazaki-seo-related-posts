よくある質問

設定や費用について、よく聞かれる質問と答えです。

選び方と精度

どの選び方がいちばんよいですか？

多くのサイトでは 「意味の近さで選ぶ（推奨）」 で十分です。記事の本文まで比べるので精度が高く、結果が毎回同じで、費用もほとんどかかりません。GPT に最終判断させたい特別な理由がある場合だけ「意味の近さ＋GPT」を選んでください。

「意味の近さで選ぶ」のとき、GPT モデルの設定は関係ありますか？

関係ありません。GPT モデルは「意味の近さ＋GPT」「従来の方式」のときだけ使います。

Embedding モデルは large にしたほうがいいですか？

通常は text-embedding-3-small で十分です。large は料金が高く、ベクトルも大きくなります。変えると全記事のベクトルを作り直します。

タグやカテゴリを付けていない記事も選ばれますか？

「意味の近さで選ぶ」では本文の内容で比べるので選ばれます。「従来の方式」ではタグ・カテゴリ・文字の一致で候補を集めるため、付けていないと候補になりにくくなります。

表示

新しい記事に関連記事が出ません。

新しい記事は「この記事で関連記事を表示する」が OFF で始まります。記事の編集画面でチェックを入れて保存してください。

カスタム設定を変えたのに一部の記事に効きません。

記事に以前の設定値が保存されています。投稿タイプ別設定の赤い「すべて現在の設定値を反映」を押してください（設定の優先順位と反映）。

「すべて有効化」と「すべて現在の設定値を反映」の違いは？

「すべて有効化」は全記事の「関連記事を表示する」を ON にするだけです。「すべて現在の設定値を反映」は、全記事に保存された設定（範囲・件数・色など）を消して、今のカスタム設定・共通設定に合わせます。ON/OFF は変えません。

新しく公開した記事は、ほかの記事の関連記事にすぐ出ますか？

新しい記事のベクトルができたあと、ほかの記事のキャッシュが期限切れで選び直されたときに出ます。すぐ出したい場合は、キャッシュをクリアしてください。

費用と API

どのくらい費用がかかりますか？

「意味の近さで選ぶ」なら、記事のベクトルを作るときだけです（text-embedding-3-small で数百記事でも 1 円未満）。関連記事を選ぶたびの費用はかかりません。GPT を使う方式は、キャッシュを作るたびに GPT の料金がかかります（キャッシュと費用）。

訪問者が増えると費用も増えますか？

増えません。訪問者がページを開いたときに OpenAI を呼ぶことはありません。関連記事はキャッシュを使い、GPT の選定もバックグラウンドで記事ごとに行います。

APIキーは安全に保存されますか？

データベースに暗号化して保存し、設定画面の HTML にも出しません。データベースに置きたくない場合は wp-config.php の定数で設定できます（技術仕様・セキュリティ）。

OpenRouter のキーは使えますか？

v1.0.4 で OpenRouter への対応をやめ、データベースに残っていた OpenRouter のキーも削除しました。OpenAI の APIキーを入れてください。

アップデート・削除

v1.0.3 からアップデートすると設定は引き継がれますか？

引き継がれます。OpenAI のキーは自動で暗号化し直し、関連記事の選び方は「意味の近さで選ぶ」になります。アップデート後に「未作成の記事をまとめて作成」でベクトルを作ってください（作り終えるまでは文字の一致の結果を表示します）。

プラグインを削除するとデータはどうなりますか？

無効化だけなら設定は残ります。管理画面から削除（アンインストール）すると、設定・記事ごとの設定・キャッシュ・ベクトル・API の記録をすべて削除します。
