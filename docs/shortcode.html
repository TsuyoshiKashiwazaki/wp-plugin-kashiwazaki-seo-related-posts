ショートコード・ウィジェット

本文への自動挿入のほかに、ショートコードやウィジェットで好きな場所に関連記事を出せます。

ショートコード

基本の書き方

[kashiwazaki_related_posts]

記事・固定ページの本文に書くと、その場所に関連記事を表示します。APIキーを設定していれば、自動挿入と同じく AI（「🤖 AIのAPI設定」タブの「関連記事の選び方」）で選びます。

パラメーター付き

[kashiwazaki_related_posts max_posts="10" template="grid" title="おすすめ記事"]
パラメーター説明省略時
max_posts表示件数5
template表示形式。list / grid / slider / card / minimallist
title見出しの文字。省略すると見出しを出しませんなし
use_aiAI で選ぶか。true / false / auto（auto は APIキーがあれば AI を使う）auto
post_types候補にする投稿タイプ（カンマ区切り）post
search_methods従来の方式・文字の一致で使う候補の集め方。tags / categories / directory / title / excerpt（カンマ区切り）すべて
filter_categoriesこのカテゴリ ID の記事だけを候補にする（カンマ区切り）全カテゴリ
exclude候補から外す投稿 ID（カンマ区切り）なし
post_id関連記事を探す元の投稿 ID表示中の投稿
show_excerpt / show_thumbnail / show_date抜粋・サムネイル・日付を出すか（true / false）true / true / false
パラメーターは、その記事のキャッシュが無いときに使われます

選んだ関連記事は記事ごとに 1 つだけ保存（キャッシュ）され、自動挿入・ショートコード・記事の編集画面の「関連記事を取得」で共通です。キャッシュが有効な間は、ショートコードの max_posts・exclude・post_types・filter_categories・search_methods・use_ai を書いても、保存済みの結果がそのまま表示されます。

  • パラメーターを書いた・変えたあとは、キャッシュを消してください。その記事の編集画面の「キャッシュクリア」（関連記事の設定欄が出ている投稿タイプ）か、投稿タイプ別のカスタム設定画面の「この投稿タイプのキャッシュをクリア」で消せます。次に表示されたときに、ショートコードのパラメーターで選び直して保存します。
  • 同じ記事で、自動挿入（「この記事で関連記事を表示する」が ON）とパラメーター付きのショートコードを併用しないでください。先に作られたほうの結果が両方に使われます。
  • template・title・show_excerpt・show_thumbnail・show_date（見た目）はキャッシュに関係なく毎回効きます。
カラーテーマはショートコードで指定しません

色は、記事ごとの設定 → 投稿タイプ別のカスタム設定 → 共通設定の順に決まります。

テーマのテンプレートで使う

<?php echo do_shortcode('[kashiwazaki_related_posts]'); ?>

single.php などに書くと、その位置に関連記事を出せます。自動挿入と二重に出ないよう、その記事の「この記事で関連記事を表示する」は OFF にしてください。

設定画面の「📚 使い方」タブ

設定画面の「📚 使い方」タブにも、セットアップの手順とショートコードの書き方が載っています。

ウィジェット

「外観」→「ウィジェット」で「Kashiwazaki SEO Related Posts」を追加すると、サイドバーなどに関連記事を出せます（記事・固定ページを表示しているときに出ます）。
