関連記事が表示されない

考えられる原因確かめる場所・直し方
その記事で「関連記事を表示する」が OFF記事の編集画面の「この記事で関連記事を表示する」を ON にして保存します。新しい記事は OFF で始まります。まとめて ON にするには投稿タイプ別設定の「すべて有効化」（投稿タイプ別設定）。
編集画面に関連記事の設定欄が無い投稿タイプ別設定で、その投稿タイプの「関連記事を表示」にチェックを入れて「表示設定を保存」。
候補になる記事が無い「関連記事に選ぶ範囲」（対象投稿タイプ・カテゴリ）が狭すぎないか確認します。範囲に公開記事が 1 件も無いと表示されません。
ページキャッシュのプラグインが古いページを出しているページキャッシュ（WP Rocket・LiteSpeed Cache など）を削除します。
テーマが本文を the_content で出していない自動挿入は the_content を使います。出ない場合はテンプレートで ショートコード を使います。

設定を変えたのに記事に効かない

考えられる原因確かめる場所・直し方
記事に以前の設定値が保存されているいちばん多い原因です。投稿タイプ別設定の赤い「すべて現在の設定値を反映」を押します（設定の優先順位と反映）。
キャッシュの期限が切れていない記事の編集画面の「キャッシュクリア」、またはカスタム設定画面の「この投稿タイプのキャッシュをクリア」。
カスタム設定が「共通設定を使用」になっているカスタム設定画面の「設定モード」を「この投稿タイプ専用の設定を使用」にして保存します。

関連なさそうな記事が出る・意味の近さになっていない

考えられる原因確かめる場所・直し方
記事のベクトルがまだ無い「ベクトルの作成状況」で左右の数がそろっているか確認し、足りなければ「未作成の記事をまとめて作成」。ベクトルができるまでは文字の一致の結果を表示します。
関連記事の選び方が「従来の方式」「🤖 AIのAPI設定」タブで「意味の近さで選ぶ」を選んで保存します。
候補の範囲に関係の薄い投稿タイプが入っている「関連記事に選ぶ範囲」から外します。
古いキャッシュが残っているキャッシュをクリアします（キャッシュと費用）。
記事の本文が短い・内容が似た記事が少ない意味の近さは本文の内容で比べるため、記事数が少ないと近い記事が見つかりにくくなります。

ベクトルの作成が進まない

考えられる原因確かめる場所・直し方
APIキーが無効・利用上限に達している「APIキーテスト」で確かめます。OpenAI でエラーが出ると、10 分間は呼び出しを止めます。
WP-Cron が動いていないDISABLE_WP_CRON を設定しているサイトやアクセスの少ないサイトでは、バックグラウンドの作成が進みません。「未作成の記事をまとめて作成」を押すか、サーバーの cron で wp-cron.php を定期的に呼んでください。
記事が長すぎる・特殊な文字が多いOpenAI が受け付けない記事は、文章を短くして送り直し、それでもだめな記事は作成失敗として飛ばします（ほかの記事の作成は続けます）。

OpenAI のエラー

考えられる原因確かめる場所・直し方
APIキーが無効・期限切れOpenAI Platform でキーを確認し、新しいキーを入れ直します。
「保存済みのキーを復号できません」と出るwp-config.php の認証用キー・ソルトが変わりました。APIキーを入れ直してください。
利用上限・残高不足OpenAI の Billing で上限と残高を確認します。
サーバーから外部に通信できないホスティングで api.openai.com への HTTPS 通信が許可されているか確認します。
OpenAI 側の障害OpenAI Status を確認し、復旧を待ちます。
GPT モデルを保存できない選んだモデルが関連記事の選定（chat completions）に使えません。別のモデルを選びます。
モデル一覧を取得できない表示されるエラーを確認します。取得できないときも text-embedding-3-small / text-embedding-3-large は選べます。

GPT を使う方式で、いつまでも GPT の結果にならない

GPT の選定はバックグラウンド（WP-Cron）で記事ごとに行います。WP-Cron が動いていないと進みません。管理者が記事の編集画面で「関連記事を取得」を押すと、その場で GPT の結果を作って保存します。

見た目が崩れる

考えられる原因確かめる場所・直し方
テーマの CSS と競合しているブラウザの開発者ツールで、テーマの CSS が .kashiwazaki-related-posts の見た目を上書きしていないか確認します。
スライダーが動かないブラウザのコンソールに JavaScript のエラーが出ていないか確認します。jQuery を読み込まないテーマ・最適化プラグインの JS 結合が原因のことがあります。
関連記事が二重に出る自動挿入とショートコード・ウィジェットを同じ記事で使っていないか確認します。

PHP 8.1 以降の互換性

v1.0.2 で、PHP 8.1 以降で出ていた Deprecated 警告（strpos() / str_replace() / strip_tags() に null を渡す警告、AJAX の未定義キー）を解消しています。アップデート後も同じ警告が残る場合は、別のプラグインやテーマが原因の可能性があります。

それでも解決しないとき

プラグインを一度無効化して再度有効化してみてください。設定はデータベースに残るので、再有効化しても消えません（削除＝アンインストールすると消えます）。
